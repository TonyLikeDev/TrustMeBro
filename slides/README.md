## 🗂 Recommended Slide Structure

### Slide 1 — Title
- Project name
- Team name
- Hackathon: IBM Bob 2.0 Hackathon 2026

### Slide 2 — The Problem
- Who has this problem (developer persona)
- What the current workflow looks like (diagram or screenshot)
- **The pain quantified**: X hours lost, Y% error rate, Z manual steps
- Why this is hard to solve without AI

### Slide 3 — Solution Overview
- One-sentence solution summary
- Architecture diagram:
  - Input → IBM Bob 2.0 (Agent mode + subagents) → Output
- Key Bob 2.0 features used (with icons)

### Slide 4 — How It Works (Technical)
- Step-by-step breakdown of the workflow
- Which Bob feature handles each step
- Any custom modes, skills, or MCP integrations

### Slide 5 — Demo Highlights
- 2–3 screenshots from the live demo
- Annotate: "Bob's Agent mode automatically..." / "Subagents running in parallel..."
- Before state → After state comparison

### Slide 6 — Impact Metrics
- Big bold numbers (make them easy to read):
  - "90% reduction in onboarding time"
  - "4 hours → 8 minutes"
  - "0 manual steps"
- Quantified before/after table

### Slide 7 — IBM Bob 2.0 Usage (Optional — reinforce the Usage Statement)
- Features used: Agent mode, subagents, custom modes, etc.
- Number of Bob tasks completed
- Screenshot of a Bob session summary (shows real usage)

### Slide 8 — What's Next (Optional)
- How this solution could be extended
- Potential real-world deployment
- Future Bob features that would enhance it

---

## 🎨 Design Tips

- **Less text, more visuals** — judges read quickly
- **Big numbers** — "4 hours → 8 minutes" in huge font stands out
- **One idea per slide** — don't cram everything in
- **Consistent colour scheme** — IBM blue (#0062FF) works well for this hackathon
- **Diagrams over bullet lists** — show the flow visually
