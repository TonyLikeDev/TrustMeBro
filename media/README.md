## 📋 Requirements

### 🎥 Video Demonstration

| Requirement | Detail |
|------------|--------|
| Format | MP4 |
| Max length | **3 minutes** (judges will NOT watch beyond 3:00) |
| Min solution demo time | **At least 90 seconds** showing your solution in action on screen |
| Narration | Required — explain what you are demonstrating |
| Content | Problem intro → solution demo → impact metrics |

### 🖼 Cover Image

| Requirement | Detail |
|------------|--------|
| Purpose | Thumbnail shown on lablab.ai submission page |
| Recommended size | 1280×720px (16:9) |
| Format | PNG or JPG |
| Content | Project name, brief tagline, team name |

## 🎬 Video Production Checklist

### Before Recording
- [ ] Script written (see template below)
- [ ] Screen recording software ready (OBS, QuickTime, Loom, etc.)
- [ ] Microphone tested — no background noise
- [ ] Bob IDE open and logged into hackathon account
- [ ] Demo project ready to show (no loading delays during recording)
- [ ] Browser/IDE windows arranged cleanly (no clutter on screen)

### During Recording
- [ ] Record at 1080p minimum
- [ ] Narrate throughout — don't silently screenshare
- [ ] Show Bob IDE running Agent mode / subagents (not just chat responses)
- [ ] Show before/after comparison if possible

### After Recording
- [ ] Edit out dead time (pauses, loading screens, mistakes)
- [ ] Verify total length ≤ 3:00
- [ ] Verify solution is shown in action for ≥ 1:30
- [ ] Export as MP4
- [ ] Watch it back fully — check audio clarity
- [ ] Name file clearly: `[project_name]_demo_v1.mp4`

## 🎬 Video Script Template

```
[0:00 - 0:25] HOOK — THE PROBLEM
"Every [developer type] on a [team type] loses [X hours/week] to [painful problem].
Today that means [describe the painful manual process].
We built [Solution Name] to change that."

[0:25 - 0:40] SOLUTION OVERVIEW (quick slide or diagram)
- Show: Input → IBM Bob 2.0 (Agent mode + subagents) → Output
- Say: "Our solution uses IBM Bob's Agent mode and parallel subagents to [one sentence summary]"

[0:40 - 2:30] LIVE DEMO ON SCREEN (most important — 90+ seconds here)
Step 1: Show the starting state (the problem/mess/manual work)
Step 2: Show triggering the solution in Bob IDE
Step 3: Show Bob's Agent mode running — files being edited, commands executed
Step 4: Show subagents working (if applicable)
Step 5: Show the output / fixed state
Step 6: Show verification (tests passing, report generated, etc.)

[2:30 - 3:00] IMPACT CLOSE
"Before: [X hours/steps/errors].
After: [Y minutes/steps/errors].
Fully automated. Verified. Built in 48 hours with IBM Bob 2.0."
```
