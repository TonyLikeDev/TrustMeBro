## 4. Critical Lessons from TEST_DES.md (Team Analysis)

The internal team analysis (`big_project_report/TEST_DES.md`) identified 4 key lessons from running the skills:

1. **Verify at runtime before ticking** — "Login works" must be checked by the agent, not delegated to the user. Bob's biggest gap was an unseeded database that only a human spotted.
2. **Run `/roadmap-sync` at each milestone boundary** — drift was found (e.g., "dev.db is seeded" when it had 0 rows, "shadcn/ui installed" when it wasn't).
3. **Keep planning overhead proportional to token budget** — on a token-limited run, lighter planning leaves more budget for building. `TEST_DES.md` estimates 27-46h remaining work for NoSkill vs 75-113h for Bob due to incomplete M1-M3.
4. **Add early nudges** toward shared tenancy guards and one smoke test per router.
