## 🔒 Credential Safety

> IBM Cloud credential exposure = **immediate account suspension**

### What NOT to Put in the Repo

- [ ] IBM Cloud API keys
- [ ] IAM tokens or service credentials
- [ ] Watson API keys
- [ ] Any `ibm_api_key`, `apikey`, `iam_apikey` values
- [ ] `.env` files with real secrets
- [ ] `credentials.json` files

### How to Protect Credentials

1. **Use `.bobignore`** — prevents Bob from reading credential files
2. **Use `.gitignore`** — prevents credential files from being committed
3. **Use environment variables** — load secrets from env, not hardcoded
4. **Use a secrets manager** — IBM Secrets Manager or similar
5. **Rotate any key you think may have been exposed immediately**

### `.gitignore` Entries to Include

```
# Credentials and secrets
.env
.env.*
credentials.json
ibm-credentials.env
*.key
*.pem
config/secrets.json

# IDE-specific
.bob/
```

### `.bobignore` Entries to Include

```
# Prevent Bob from reading credential files
.env
.env.*
credentials.json
ibm-credentials.env
```
