## 🧩 Example Problem Statements for Inspiration

### Option A — Developer Onboarding
> New developers joining a large codebase spend 2–3 days reading docs, setting up environments, and
> asking teammates where to start. 40% of setup steps are outdated. IBM Bob 2.0 can analyze the repo
> live, generate a verified setup guide, produce an architecture map, and suggest first tasks —
> cutting onboarding from days to under 2 hours.

### Option B — Code Review Automation
> Pull request review takes 3–5 hours per PR, with reviewers missing ~25% of logic bugs due to
> context switching. IBM Bob 2.0 can run parallel subagents to check security, test coverage, logic
> correctness, and style — generating a structured review report before any human reviewer looks.

### Option C — CI Failure Triage
> When CI breaks, developers spend 45–90 minutes reading logs, bisecting commits, and guessing root
> causes. IBM Bob 2.0's Agent mode can analyze the full repo context, pinpoint the failing change,
> and suggest a verified patch — reducing triage time to under 5 minutes.

### Option D — Release Readiness
> Before a production release, teams manually check 20+ checklist items across logs, dependencies,
> tests, and docs — taking 4 hours and missing items 30% of the time. IBM Bob 2.0 automates the
> entire pre-release audit and generates a risk-scored report with go/no-go recommendation.
