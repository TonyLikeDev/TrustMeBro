---

## 🪜 Step-by-Step: How to Capture a Bob Task Session Summary

1. In **Bob IDE**, open the chat interface
2. Click the **Tasks** tab (top of the chat panel) to display the task list
3. If your project spans multiple workspaces, select **All** to view tasks across workspaces
4. Select a task related to your project — it will open in the chat panel
5. Click the **task header** at the top of the task conversation
6. A **task session consumption summary** will appear
7. Take a **screenshot** of that summary
8. Save the screenshot in **PNG format** (better text clarity than JPG)
9. Use this naming convention:

```
teamname_task##_short_description_summary.png

Examples:
  myteam_task01_codebase_analysis_summary.png
  myteam_task02_test_generation_summary.png
  myteam_task03_security_audit_summary.png
  alice_task04_review_workflow_summary.png
  bob_task05_deployment_check_summary.png
```

10. Upload the screenshot to **this folder** (`bob_sessions/`)
11. Repeat for **all tasks** related to your project
